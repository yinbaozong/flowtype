# FlowType 0.6.2

- 改为模型确认新增文字后立即输出，不再在软件中统一等到整句结束；结束时只补剩余文字。
- 合并回填期间陆续到达的文字，避免小增量形成长队列；继续使用原输入框，不增加文字弹窗。
- 默认使用按需开启麦克风：空闲时只预加载音频处理器，按键时才申请麦克风，松手或放弃后释放。
- 将每次录音重复创建的 AudioContext/AudioWorklet 改为可复用处理链路，并将音频数据块减小至 20ms。
- 冷启动期间显示准备状态，实际采集启动后变为录音状态，并记录按键到启动的耗时以便排查。
- 设置中提供可选的麦克风预热，默认关闭；启用后 Windows 可能显示麦克风占用，但空闲时音轨禁用，不上传音频。
- 重试时跳过已输出的确认前缀，避免未结束句子的开头重复输入。

千问可能按几个字或短片段确认结果，因此连续出字仍受模型和网络延迟影响，不保证逐字零延迟。按键前说出的声音不会被补录；选择按需开启时，硬件打开仍可能有短暂准备时间。

连续输出时，撤销作用于当前应用最近一次输入操作，可能是一小段而非完整句子。整段识别模式仍可在设置中选择。

验证包含：确认前缀提前输出、最终结果去重、失败重试前缀去重、输出队列合并、默认空闲不申请麦克风、复用/释放采集资源、模拟麦克风采集及实际千问合成语音端到端测试。未操作用户桌面输入框。
