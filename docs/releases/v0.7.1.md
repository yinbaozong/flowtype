# FlowType 0.7.1

- 设置页增加“当前生效”和“待保存”配置摘要，显示实际服务、模型 / 资源 ID 和凭证尾号。
- 每家已保存的 Key 显示末尾 8 位。过短凭证不显示尾号，完整已保存密钥和加密密文不发送给界面。
- 每份 API 凭证提供“保存并使用此服务”按钮；录入哪家的 Key，就选择对应的待保存服务，不再只有千问能自动选择。
- 侧栏使用已保存配置实时更新模型和凭证标识，不把“已配置”当作“连接成功”，也不会静默回退到另一家。
- 历史或录音状态刷新不再重置未保存的服务选择。
- 新填写豆包 API Key 时清除旧版 Access Token，避免旧凭证覆盖新 Key；使用旧版鉴权时显示 Access Token 尾号。

当前服务切换与连接权限是两件事。服务返回 403 时需在对应控制台开通权限，界面显示服务名不表示该服务已经验证可用。

已通过凭证脱敏、模型派生、旧凭证优先级、设置切换和历史刷新回归，以及隐藏窗口内部测试。未操作用户真实输入框。
