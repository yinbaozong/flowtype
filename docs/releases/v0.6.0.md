# FlowType 0.6.0

## 实时出字与长段输入

- 千问默认使用 `qwen3-asr-flash-realtime`：边说边预览，临时草稿持续修订，自然停顿后将定稿句输入原输入框。
- 松开快捷键后等待最后一句定稿；保留整段识别模式和火山原有服务。
- AudioWorklet 在独立隐藏窗口中采集音频，悬浮条恢复不会销毁录音；单次上限延长至 30 分钟。
- 失败后提供一次手动重试，跳过已完成部分；音频仅保存在内存中，重试失败、放弃、开始新录音或退出后释放。
- 已识别文字与未定稿草稿保存在本机，文字日志支持异常退出恢复；Markdown 导出包含模型和部分完成标记。
- 使用常驻输入辅助进程串行回填；切换输入目标或手动编辑后停止自动输入，结果仍保存在历史中。
- 撤销快捷键撤回最近插入的一句，手动编辑后禁用自动撤销。
- 独立实时预览支持中英文，随悬浮条一起隐藏；保留绿色波形、原位置与 44px 最小宽度。

## 内部验证

- 分句草稿修订、乱序、去重、过期连接与快速松手。
- 超过一分钟录音、收尾超时、未识别尾部重试、仅一次重试。
- 整段模式的有界请求、部分完成记录和重试去重。
- Windows 原生代码编译、常驻输入辅助进程协议与焦点拒绝，未发送测试按键。
- 隐藏测试窗口中的模拟麦克风采集、尾帧、预览布局、按钮与中英文切换。
- 实际千问实时接口：通过合成语音验证结束前的实时预览与最终分句，未使用真实麦克风。

## 下载

- 安装版：`FlowType Setup 0.6.0.exe`。
- 免安装版：`FlowType Portable 0.6.0.zip`，需完整解压后运行。
- 两种方式继续使用 `%APPDATA%\FlowType` 中的历史与设置。

实时识别需要现有千问 Key 拥有实时模型权限。整段模式在松手后识别。整个软件退出后，尚未识别的内存音频无法恢复；已保存文字仍在历史记录中。
