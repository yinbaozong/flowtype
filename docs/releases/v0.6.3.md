# FlowType 0.6.3

## 修复与优化

- 修复实时音频被重复逐块限速的问题，避免 Windows 定时器延后时越说越积压、松手后长时间转圈。
- 松手后可以立即再次按快捷键录音，不再被上一轮云端收尾锁住。文字按录音顺序回填；没有新增文字弹框。
- 上一轮迟到的音频、停止确认或错误不再影响新一轮麦克风和悬浮条；取消、失败和采集停止超时都会释放等待。
- 等待期间可以正常手动打字或切换位置；旧自动回填随之失效，后续识别结果保留在历史中，不抢回焦点。
- 增加发送积压、首次确认结果、收尾、输入辅助进程耗时等诊断日志，不记录 Key、音频或识别正文。

同一段约 10 秒合成语音的真实接口对照中，松手到收尾从 5.85 秒降至 67ms。这是内部测试样例，不是逐字零延迟承诺；真实速度仍受模型和网络影响。详细数据与复现方式见仓库 `docs/latency-0.6.3.md`。

默认仍仅在按键时打开麦克风。历史、API Key、快捷键、悬浮条位置及 44px 最小宽度保持兼容。

## 下载

- 安装版：`FlowType.Setup.0.6.3.exe`
- 免安装版：`FlowType.Portable.0.6.3.zip`，需完整解压后运行 `FlowType.exe`。

两种文件放在同一个 Release。安装包未使用商业签名，Windows 安全策略仍可能拦截未知发布者；ZIP 保留原始 Electron 运行程序，不保证绕过任何安全策略。

验证包括内部回归、隐藏窗口模拟采集、真实千问合成语音接口、类型检查、构建和两种打包。未操作用户的真实输入框。
