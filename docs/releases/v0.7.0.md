# FlowType 0.7.0

- 新增 DeepSeek 官方语音识别（整段模式），使用语音 ASR 接口，而非聊天模型。
- 新增豆包 / 火山引擎实时识别，支持 2.0 / 1.0 小时版和并发版资源选择，兼容语音 Key 和旧版鉴权。
- 设置页标注各服务能力和凭证区别；保留原千问及火山整段模式。
- 新增凭证加密保存、分句去重、快速松手、收尾超时和一次重试的内部测试。

默认仍按需打开麦克风，不自动改变已选服务和配置。换模型不能保证消除硬件打开时间；按键后等待波形变绿再开口，或按个人偏好手动启用预热。

DeepSeek 暂不支持实时语音识别。豆包实时按已定稿分句回填，不把易变草稿直接插入输入框。两家新服务均需用户自己的语音权限及余额；已验证内部协议及实际未授权响应，真实识别效果需开通相应语音资源后验收。配置 Key 成功不等于服务已授权。

配置说明见仓库 `docs/speech-providers.md`。安装版和完整解压版放在同一个 Release。
