# FlowType 0.6.1

- 修复识别成功却未输入的问题：为异步粘贴保留剪贴板读取时间，再按条件恢复原剪贴板。
- 仅由录音监听器报告手动编辑，避免两个监听器的消息顺序误停文字回填。
- 在原输入框所在窗口内解析可用焦点，兼容快捷键开始时未取得子控件句柄的情况；不抢其他窗口的焦点。
- 移除独立文字预览弹框及其设置，保留小波形条，定稿句直接进入原输入框。
- 将一次重试和放弃入口移到历史记录中，原配置与历史继续保留。
- 增加延迟读取剪贴板、取消过期输入、保护后续复制内容的回归测试及回填结果日志。

内部验证不向用户桌面发送测试按键。真实应用中的文字输入由用户手动验收。

同一 Release 提供 `FlowType Setup 0.6.1.exe` 和 `FlowType Portable 0.6.1.zip`。
